# Google Sheets application backend

This Apps Script appends job applications to the existing Google Sheet without changing row 1.

The row order is fixed to the existing columns A-K:

1. Time (generated by the server)
2. Name
3. Phone number
4. Past-job mistake
5. Workplace disagreement
6. Task tracking
7. Feedback preference
8. Outdoor experience
9. Individual or team work style
10. Availability
11. Machinery experience and weak spots

## Deploy

1. Open the application spreadsheet.
2. Select **Extensions → Apps Script**.
3. Replace the editor contents with `Code.gs` from this folder.
4. Select **Deploy → New deployment**. For later script changes, use **Deploy → Manage deployments**, edit the existing deployment, and select **New version**.
5. Choose **Web app** as the deployment type.
6. Set **Execute as** to **Me**.
7. Set **Who has access** to **Anyone**.
8. Deploy, authorize the script, and copy the URL ending in `/exec`.
9. Put that URL in `.env.production.local` as:

   `VITE_APPLICATION_ENDPOINT=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec`

10. Rebuild the site and upload the new Cloudflare deployment.

The Sheet should stay private. Applicants receive access only to the web app, which can append validated rows but cannot expose or edit existing applications.

The website deployment must include `public/application-result.html`. Apps Script redirects its hidden response frame to this same-domain page so the application form can reliably display success, rate-limit, or error feedback.
